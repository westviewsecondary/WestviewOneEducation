ONEEDUCATION SCHOOL HUB UPDATE

This ZIP contains files directly at its root. There are no folders inside it.

EXISTING ONEEDUCATION SCHOOL
1. Save any outstanding MIS changes and close your school tabs.
2. Open the SAME OneEducation Supabase project: naxoplmtweovwaiwvexe.
3. In SQL Editor, run the entire ONEEDUCATION-HUB-UPGRADE.sql file.
4. Upload every website file from this ZIP to the ROOT of your existing GitHub repository. Allow GitHub to replace files with matching names.
5. Wait for GitHub Pages to finish publishing. Hard-refresh the page and sign in.
6. Open Administration and scroll to “Choose what students can see”.

No student reset is needed. The upgrade preserves your existing school workspace, student codes, memberships, sets, timetables and exams. Hub records use new tables so normal MIS saves cannot overwrite submissions or bookings.

NEW STAFF SECTIONS
- Staff hub: notices, policies, department resources, useful links and downloadable forms.
- Homework: publish to a class, tutor group, year or the whole school; set a due date; attach a file; review submissions with feedback and a grade.
- Reports: choose a student, subject and term; enter grade, effort and comments; save as a draft or publish; print a combined report or save it as PDF using your browser.
- Parents’ evening: create teacher appointment slots. Only pupils taught by that teacher can book. Slots cannot overlap for a teacher and pupils cannot make conflicting bookings.
- Office helpdesk: staff and students submit IT, lost-property, room or general requests. Staff reply and update status.
- Clubs & trips: set an audience, date, location and capacity. Families request places and declare consent where required. Staff review, approve or cancel participants and export a list.
- Revision hub: publish subject resources and attachments. Students add dated personal checklists and mark a revision session complete.

PORTAL VISIBILITY
Administration > Choose what students can see.
“Everyone” sets the school default. Choose a named student to override any section with Show, Hide or Use school default.
Available controls: Timetable, Classes, Exams, Notices, Homework, Reports, Parents’ evening, Office helpdesk, Clubs & trips and Revision hub.
Only administrators can change these settings. Hidden sections are filtered at the database as well as the website. A student’s submitted work is retained when a section is hidden and reappears if you show it again.
The portal refreshes access on sign-in, on Refresh, and periodically while open. Previously downloaded or printed information cannot be recalled.

SAVING
New hub forms save immediately to Supabase.
The existing bottom “Save changes” button still saves the original MIS records.
Demo mode lets staff try the new forms without saving to Supabase. The live student portal requires a saved student and a valid code.

ATTACHMENTS
Up to 2 MB per record or submission. Supported: PDF, PNG, JPG, TXT, CSV, DOCX, XLSX and PPTX.
For larger resources, use the resource-link field. Attachments are stored in access-controlled hub records and download only with the relevant staff/student access.

FAMILY ACCESS AND CONSENT
Parents use the child’s private code, as in the original system. Consent includes a parent/guardian name and declaration; it does not independently verify the adult’s identity. Staff should verify consent before approving participation. This update sends no automatic emails or text messages.

TIMETABLE NOTES
The update preserves any linked-set SQL you already ran. The existing Generate timetables button still overwrites that customised layout, so do not use it after linked-set setup.
Week B in timetable-ab.html is still a proposed preview, not an active two-week calendar.
This update does not run the English Literature exam replacement or linked-set SQL automatically.
