ONEEDUCATION TIMETABLE GRID ADD-ON

Upload timetable-ab.html, timetable-ab.css and timetable-ab.mjs beside your existing index.html. These are new filenames. Do not replace any existing files. This add-on uses the existing config.js, api.mjs, core.mjs and seed.mjs. No extra SQL is required.

Open your existing website address with timetable-ab.html instead of index.html. Bookmark that page. The original navigation is unchanged because none of the existing files have been replaced.

Staff sign in with their existing account. Students and families use the existing student code. A fictional demo is available before database setup.

Week A displays existing saved lessons. Week B is a proposed whole-day rotation: Monday uses Wednesday's lessons, Tuesday Thursday's, Wednesday Friday's, Thursday Monday's, Friday Tuesday's. Applying the same mapping to every class preserves existing allocation conflicts without inventing new class memberships.

This is a read-only grid and Week B preview, not an activated two-week school calendar. Date-specific exams, cover, removals and closures remain in the main MIS and student portal. Existing attendance, cover and portal code continue using their original weekly schedule. Activating Week A/B across those features requires updating those existing files and is not done by this add-on.

The timetable prints in landscape using your browser print settings.
